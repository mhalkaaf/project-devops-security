# Roadmap Belajar

## Minggu 1–2: runtime dan CI

- Selesaikan project 01 dan 02.
- Jelaskan PID 1, signal handling, health check, image layer, cache, dan least privilege.
- Hasil: pull request kecil dengan test, scan, dan image build yang reproducible.

## Minggu 3–4: IaC dan Kubernetes

- Selesaikan project 03 dan 04.
- Praktikkan plan review, state safety, rollout, rollback, probes, resources, dan network policy.
- Hasil: cluster lokal dapat dibangun dan dihapus dari dokumentasi saja.

## Minggu 5–6: GitOps dan observability

- Selesaikan project 05 dan 06.
- Buat manual drift, latency, dan error incident.
- Hasil: perubahan dapat diaudit dan insiden dapat didiagnosis dari telemetry.

## Minggu 7–8: supply chain dan platform

- Selesaikan project 07 dan 08.
- Definisikan policy exception lifecycle dan satu golden path.
- Hasil: insecure artifact ditolak lebih awal dan service baru memiliki baseline konsisten.

## Portofolio

Untuk setiap tahap simpan diagram, screenshot dashboard, contoh pull request, hasil incident drill, keputusan trade-off, dan retrospektif. Nilai portofolio berasal dari penjelasan mengapa sistem dibuat demikian, bukan jumlah tool yang dipasang.
